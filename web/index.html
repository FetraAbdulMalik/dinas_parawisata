Informasi singkat untuk memilih cara menggunakan Guriang Garut.

Apa itu Guriang Garut?

Aplikasi panduan wisata dan budaya untuk membantu menemukan destinasi, melihat peta, membaca cerita, serta menyimpan tempat favorit.

Apa bedanya website dan aplikasi Android?

Website bisa langsung digunakan di browser. APK dapat dipasang di perangkat Android. Keduanya menjalankan aplikasi Guriang Garut.

Apakah website memerlukan pemasangan?

Tidak. Pilih “Buka Website” dan aplikasi akan berjalan langsung di browser. Koneksi internet diperlukan untuk membuka halaman web.

Bagaimana cara memasang APK?

Unduh APK melalui tombol di halaman ini, buka berkasnya di perangkat Android, lalu ikuti petunjuk pemasangan perangkat.

Siap menemukan cerita Garut?

Buka aplikasi langsung dari browser, atau unduh APK untuk memasangnya di ponsel Android.
